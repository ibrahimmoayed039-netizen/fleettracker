# Agrimatco - Fleet — دليل سريع

نظام متابعة مركبات: **تطبيق أندرويد للسائق** (Kotlin) + **برنامج حاسوب للمدير** (Electron)، والربط بينهما عبر **Firebase**.

## هيكل المشروع
```
FleetTracker/
├─ .github/workflows/build.yml   ← بناء APK و EXE تلقائياً
├─ android/                      ← تطبيق السائق
│  └─ app/google-services.json   ← (تضيفه أنت من Firebase)
├─ desktop/                      ← برنامج المدير (main.js, preload.js, index.html)
│  └─ assets/                    ← الشعار والأيقونة (logo.png, icon.ico, icon.png)
├─ FIREBASE_SETUP.md             ← خطوات إعداد Firebase
└─ README.md
```

## 1) البناء على GitHub
1. ارفع المحتوى كاملاً إلى مستودع (فرع `main`).
2. تبويب **Actions** ← انتظر نجاح Build.
3. من **Artifacts** حمّل: `app-apk` (للهاتف) و `desktop-exe` (للحاسوب).

> **التحديث فوق النسخة القديمة:** الملف `android/app/fleet-sign.jks` هو مفتاح توقيع التطبيق، ارفعه مع المستودع ولا تحذفه ولا تغيّره. رقم الإصدار يزيد تلقائياً مع كل بناء. **أول مرة فقط** بعد هذا التعديل امسح النسخة القديمة (لأنها موقّعة بمفتاح مختلف)، وبعدها كل نسخة تُثبَّت فوقها مع بقاء بيانات السائق.

## 2) إعداد Firebase (مرة واحدة)
1. أنشئ مشروعاً ← **Realtime Database** (وضع Locked).
2. Authentication ← فعّل **Email/Password**.
3. Rules ← الصق القواعد من `FIREBASE_SETUP.md` ← Publish.
4. Project settings ← **Add app** ← Android ← الحزمة `com.fleet.tracker` ← حمّل `google-services.json` وضعه في `android/app/` (حمّله بعد إنشاء قاعدة البيانات).
5. انسخ **Web API Key** و**رابط قاعدة البيانات** (للحاسوب).

## 3) برنامج الحاسوب (المدير)
| التبويب | الوظيفة |
|---|---|
| السائقون | بطاقة لكل سائق: المسافة، نقاط التوقف، الفواتير |
| التفاصيل | جدول النقاط والمسافة بين كل نقطتين |
| الفواتير | صور الفواتير القادمة من الهواتف |
| إدارة السائقين | إضافة سائق (اسم، مستخدم، كلمة مرور، مركبة) / تعديل / تعطيل |
| التفاصيل ← اختر سائقاً | جدول الرحلات فيه زر **🗑 حذف** لكل رحلة (يحذفها مع نقاطها من البرنامج ومن هاتف السائق عند مزامنته) |
| الإعدادات | بيانات Firebase، حساب المدير، كود الإعداد |

**أول تشغيل:** الإعدادات ← الصق API Key والرابط ← حفظ ← اختر كلمة مرور ← **إنشاء حساب المدير** (افعلها فوراً أول مرة).

## 4) تطبيق السائق
- **الحساب:** اسم المستخدم + كلمة المرور فقط (مع `google-services.json`). بدونه يُطلب «كود الإعداد» من الحاسوب.
- **الرحلة:** تسجيل نقطة توقف + قراءة العداد ← تُحسب المسافة تلقائياً.
- **الفواتير:** تصوير أو اختيار صورة + ملاحظة ومبلغ.
- **المزامنة:** تلقائية بعد كل إضافة/حذف، وتُعاد عند فتح التطبيق إن فشلت. الخروج يرسل البيانات ثم يمسحها من الهاتف.
- البيانات محفوظة محلياً حتى بعد إغلاق التطبيق.
- **العمل دون إنترنت:** كل تسجيل (رحلة، توقف، فاتورة، حذف) يُحفظ على الهاتف فوراً ويدخل طابور إرسال. يُرسل تلقائياً عند توفر الاتصال عبر WorkManager حتى لو كان التطبيق مغلقاً (إعادة محاولة تدريجية + فحص دوري كل 15 دقيقة). يظهر في أعلى الشاشات شريط «بانتظار الإرسال / كل البيانات مرسلة». الخروج من الحساب لا يتم إلا بعد نجاح الإرسال حفاظاً على البيانات. تسجيل الدخول الأول فقط يحتاج إنترنت.

## الأمان (ملخص)
- كل سائق يرى ويكتب بياناته فقط؛ المدير (`admin@fleet.local`) يرى الكل.
- تعطيل السائق من الحاسوب يوقف إرساله فوراً.
- لا يوجد تغيير لكلمة المرور من البرنامج: عطّل الحساب وأنشئ اسماً جديداً.

## أخطاء شائعة
| المشكلة | الحل |
|---|---|
| `OPERATION_NOT_ALLOWED` | فعّل Email/Password في Authentication |
| `HTTP 401` أو Permission denied | تأكد من نشر القواعد وتسجيل دخول المدير |
| السائق يظهر «الحساب غير مفعّل» | فعّله من «إدارة السائقين» |
| فشل بناء GitHub | افتح سجل Actions وأرسل الخطأ |

## أفكار قادمة
تتبع GPS تلقائي · تقرير Excel/PDF · تنبيه صيانة بالكيلومترات · تغيير كلمة المرور من تطبيق السائق · تقرير مصروفات شهري


## الهوية البصرية (Agrimatco - Fleet)
- **الشعار:** `desktop/assets/logo.png` (شفاف) و`icon.ico` لأيقونة برنامج الحاسوب؛ وفي الأندرويد `res/mipmap-*` (أيقونة التطبيق) و`res/drawable-nodpi/logo.png` (الشعار داخل التطبيق).
- **الاسم** `Agrimatco - Fleet` يظهر في: عنوان النافذة، ترويسة البرنامجين، اسم التطبيق على الهاتف، اسم ملف التثبيت، وأعلى كل صفحة PDF.
- **PDF (الحاسوب):** زر «📄 حفظ PDF» في تبويب التقارير يحفظ الملف مباشرة والشعار والاسم ورقم الصفحة في كل صفحة. زر «🖨️ طباعة» يطبع بنفس التنسيق (للحصول على الترويسة في كل الصفحات عند الطباعة العادية فعّل «Headers and footers» في نافذة الطباعة).
- **تغيير الألوان:** حاسوب ← أول ملف `index.html` (متغيرات `--g1 --g2 --g3`)، وأندرويد ← `res/values/colors.xml` وكائن `Brand` في `Screens.kt`.
